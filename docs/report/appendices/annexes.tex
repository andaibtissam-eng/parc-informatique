\section{Annexe B -- Elements techniques conserves}
Les détails techniques complets restent disponibles dans le dépôt du projet. Pour ne pas alourdir le rapport final, les annexes ne reproduisent plus les longs extraits de code ni les captures Swagger complètes. Les chapitres principaux conservent les éléments essentiels: architecture, modèle de données, sécurité, développement, tests et déploiement.
