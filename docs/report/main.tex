\frontmatterchapter{Résumé}
\begin{frontmattertext}
Ce mémoire présente la conception et la réalisation d'une plateforme web intelligente dédiée à la gestion du parc informatique et des affectations matérielles. L'objectif principal du projet consiste à structurer, sécuriser et automatiser les opérations liées à l'inventaire, aux mouvements d'équipements, au suivi des maintenances, aux notifications et à la traçabilité des actions métiers.

La solution proposée s'appuie sur une architecture moderne articulée autour d'un frontend React, d'un backend Spring Boot, d'une base de données PostgreSQL, d'API REST sécurisées par JWT, d'une communication temps réel par WebSocket ainsi que d'un déploiement conteneurisé via Docker. Le rapport détaille l'analyse des besoins, la modélisation UML, les choix architecturaux, la conception de la base de données, la mise en œuvre technique, les considérations UI/UX, les tests, le déploiement et les perspectives d'amélioration.

Le résultat final met en évidence une plateforme cohérente, évolutive et orientée métier, capable d'améliorer la visibilité sur les actifs informatiques, de fiabiliser les processus d'affectation et de renforcer la qualité du pilotage opérationnel.

\textbf{Mots-clés :} parc informatique, affectation matérielle, React, Spring Boot, PostgreSQL, JWT, WebSocket, Docker, UI/UX, reporting.

\textbf{Apports principaux :} centralisation de l'inventaire, sécurisation des accès, suivi des demandes de matériel, pilotage des maintenances, notifications en temps réel et génération de rapports exploitables.
\end{frontmattertext}

\frontmatterchapter{Abstract}
\selectlanguage{english}
\begin{frontmattertext}
This report presents the design and implementation of an intelligent web platform dedicated to IT asset management and equipment assignment workflows. The main objective is to structure, secure and streamline the operational processes related to inventory supervision, assignment lifecycle management, maintenance follow-up, notification handling and action traceability.

The proposed solution relies on a modern technical stack composed of a React frontend, a Spring Boot backend, a PostgreSQL database, JWT-secured REST APIs, WebSocket-based real-time communication and Docker-enabled deployment. The report covers requirements analysis, UML modeling, system architecture, database design, implementation details, UI/UX choices, testing strategy, deployment workflow and future improvements.

The final outcome highlights a scalable and business-oriented platform that improves operational visibility, strengthens governance over IT assets and supports a more reliable decision-making process within institutional environments.

\textbf{Keywords:} IT asset management, equipment assignment, React, Spring Boot, PostgreSQL, JWT, WebSocket, Docker, UI/UX, reporting.

\textbf{Main contributions:} centralized inventory, secure access control, equipment request tracking, maintenance monitoring, real-time notifications and usable report generation.
\end{frontmattertext}
